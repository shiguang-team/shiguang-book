# Alpha 现场演示

## 零、演示前环境准备（提前 3 分钟完成）

1. **确认容器运行正常**：执行 `docker compose ps`，确保 `shiguang-mysql`、`shiguang-backend`、`shiguang-web` 均为 `Up / healthy`。
2. **重置干净演示数据（可选）**：运行 `bash deploy/reset-demo.sh`（Windows 按 `README.md` PowerShell 命令执行），重置为 3 个演示账号 + 12 本带封面教材。
3. **浏览器准备**：打开两个窗口以便切换角色——**普通窗口**（扮演卖家 `13800000001`）、**无痕窗口**（扮演买家 `13800000002`），密码均为 **`123456`**。
   > 注意：后端已实现防暴力破解（错 5 次锁 10 分钟）与禁止给自己的书留言校验，演示留言务必使用不同账号。

---

## 一、阶段一：买家淘书、多维检索与收藏询价（0:00 ~ 2:30）

- **操作窗口**：无痕窗口（初始为**未登录状态**）
1. **免登录浏览首页**（`http://localhost`）：展示卡片流、分类标签、成色与价格。
2. **多条件组合检索**：
   - 输入关键词“计算机”或选择分类“教材”；
   - 输入价格区间 `15 ~ 40`，切换排序为 **“成色从高到低”**，点击搜索；
   - 口播亮点：后端对 `book` 表建立了 `(deleted, status, category, created_at DESC)` 最左前缀联合索引，5000 条压测消除 `Using filesort`，查询耗时从 68ms 降至 4ms。
3. **进入书籍详情页 & 登录回跳**：
   - 点开卖家 `13800000001` 发布的书籍详情页；
   - 点击 **“加入收藏”** → 触发登录拦截提示并自动携带 `redirect` 参数跳至 `/login`；
   - 使用买家账号 **`13800000002 / 123456`** 登录 → 自动精准回跳到刚才的书籍详情页。
4. **收藏与站内留言**：
   - 点击 **“加入收藏”**（展示按钮防抖 loading 与状态切换）；
   - 在底部留言框输入 `“学长你好，这本书可以在图书馆一楼自提吗？”` 并点击发送，留言即时展示在列表中。

## 二、阶段二：卖家未读提醒、发布编辑与安全注销（2:30 ~ 5:30）

- **操作窗口**：普通窗口（登录卖家账号 **`13800000001 / 123456`**）
1. **未读留言红点提醒**：
   - 登录后观察顶部导航栏用户名右上角出现 **未读红点 `1`**（由 `NavBar.vue` 轮询 `/api/messages/unread-count` 驱动）；
   - 点击进入 **个人中心 → 「我收到的留言」**，看到买家刚发的自提询价，同时自动调用 `PUT /api/messages/read-all`，导航栏红点实时清零。
2. **发布新书与封面上传**：
   - 点击顶部 **“发布书籍”**，填写书名、分类、成色、价格，上传一张本地测试封面图（< 2MB），点击发布并跳转到新书详情页。
3. **复用表单编辑回填（展示 BUG-11 修复）**：
   - 回到 **个人中心 → 「我发布的书籍」**，点击刚发布书籍的 **“编辑”**（跳转到 `/publish?id=xx`），展示原数据自动回填，将价格调低后保存；
   - 再点击顶部 **“发布书籍”**，确认表单干净重置、无旧数据残留。
4. **下架原因记录与一键恢复上架**：
   - 在个人中心对某本书点击 **“下架”**，弹窗填写原因 `“已约好周六图书馆面交”`，确认下架；
   - 展示操作栏变为 **“重新上架”**（后续可演示恢复上架并自动清空原因）。

## 三、阶段三：边界保护、删书降级与移动端适配（5:30 ~ 7:15）

1. **已下架书籍拦截新留言**：
   - 切回买家无痕窗口，打开刚才下架的那本书（或演示数据第 12 本），展示灰色 `已下架` 标签与下架原因提示条，且留言输入框已隐藏（后端同时通过 `409 Conflict` 兜底拦截）。
2. **删书防空指针降级展示（BUG-13 亮点）**：
   - 卖家窗口在个人中心逻辑删除一本买家已收藏的书；
   - 切回买家窗口点击顶部 **“我的收藏”** → 页面不报 500 错，而是安全降级展示 **“【该书籍已被卖家删除】”** 灰标卡片，并演示一键 **“移除收藏”**。
3. **退出登录与 Token 黑名单**：
   - 点击 **“退出”**，说明后端已调用 `POST /api/auth/logout` 将原 JWT 写入 `ConcurrentHashMap` 内存黑名单并配合定时任务清理，无需额外部署 Redis 即可在 2C2G 服务器实现真正注销。
4. **移动端响应式适配展示**：
   - 按 `F12` 切换设备模拟器至 **iPhone SE (375×667)**，展示首页自适应双列卡片流与精简版分页条，无横向溢屏。
