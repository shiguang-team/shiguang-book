## 四、性能与索引优化对比（5,000 条数据）
- 建立联合索引 `idx_del_status_cat_created (deleted, status, category, created_at DESC)` 后，消除了 `Using filesort`，首页多条件分页查询耗时从 **68ms 降至 4ms**。
- 2C2G 学生机服务器在限制 JVM `-Xmx512m` 与轻量内存黑名单机制下，内存占用稳定在 **62%**。
